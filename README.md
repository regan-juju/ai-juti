# AI জুটি (Android)

Claude ও ChatGPT একসাথে কাজ করানোর মোবাইল অ্যাপ। নিচে তিনটি ট্যাব থাকে: **AI জুটি**, **Claude**, **ChatGPT**।
Claude ও ChatGPT ট্যাবে নিজের সাবস্ক্রিপশন অ্যাকাউন্টে একবার লগইন করলেই চলে।

## APK ডাউনলোড
এই রিপোজিটরির **Releases** অংশে সর্বশেষ `AI-Juti.apk` আছে।
